# Secure File Storage Application

# 

# A secure file storage application that allows authenticated users to upload, manage, organize, and share files.

# 

# Users can control whether their files are public or private. Public files can be accessed through a shareable link, while private files are protected through authentication and ownership-based authorization.

# 

# The application supports large file uploads of at least 100 MB, including file validation, upload progress, and error handling.
